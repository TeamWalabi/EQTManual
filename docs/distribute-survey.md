# 6. Distribute survey

To distribute a survey to selected respondents, it must be published with a distribution list. In the ReGeNL project, the action line coordinator can help with exporting the required details from the CRM system. The distribution list contains anonymized respondents identified by a personal ID.

A survey can be distributed via multiple methods such as anonymous links, emails, personal links, or QR code.

If a distribution list is to be used, the distribution list must be first imported to Qualtrics. In Qualtrics, under the ‘Directories’ header, select the option ‘Lists’, then click on ‘Upload a file’ (see arrows, Figure 21). Note that more embedded data fields such as specific identifiers (e.g., farm name) can be added here to the distribution list if desired.



**Figure 21. Upload distribution contact list**

![Figure 21. Upload distribution contact list](assets/image7.png)

The user can then click on the ‘Distributions’ header to generate a trackable link for each contact (Figure 22). This will create unique survey links for custom distributions for each contact on the distribution list.



**Figure 22. Create distribution link**

![Figure 22. Create distribution link](assets/image70.png)

A pop-up window will appear where the user can select the desired distribution contact list from their library (Figure 23). A CSV file will be exported containing the personal links for all contacts.
